deadlocker was installed to ~/.local/bin.

1. Make sure ~/.local/bin is on your PATH
If the command is not found in a new terminal, add it:

zsh:   echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
bash:  echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bash_profile
fish:  fish_add_path $HOME/.local/bin

2. Start Docker
Deadlocker runs real MySQL servers in containers it manages itself, so a Docker daemon has to be running.

3. Run it

deadlocker

That serves the interface on http://127.0.0.1:8899 and creates a cases/ directory beside wherever you started it. The library page offers to import the worked examples — gap locks, deadlocks, metadata locks, one per behaviour — the first time it is empty.

Without the interface
Scenarios can be run from the command line, which exits non-zero when one stops behaving as it claims:

deadlocker run                              # every scenario
deadlocker run classic-ab-ba-deadlock       # one of them
deadlocker run -format junit -o results.xml # for CI

An MCP endpoint is served at /mcp for agent clients, and an optional assistant can be pointed at any OpenAI-compatible endpoint from the Settings page. Neither is required.
